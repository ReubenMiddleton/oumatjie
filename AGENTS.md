# AGENTS.md

- This repository is public. Don't add secrets, private or local artifacts, machine-specific user paths, or private environment details.
- In local interactive sessions, don't commit, push, or open or merge pull requests unless the owner asks.
- Before changing established product behaviour, search `docs/DECISIONS.md` for relevant decisions; record genuinely new product decisions there.
- When progress needs the owner's decision, credentials or accounts, log it in `docs/NEEDS_YOUR_INPUT.md` (existing format) instead of guessing, and carry on with unblocked work.
- Oumatjie Android and device operations explicitly target `emulator-5558` and fail if that serial is unavailable. See `docs/SETUP.md`.
